Overview

This vignette reproduces the PopED mrgsolve tutorial on fakinumab first-in-human PK: a two-compartment model with linear and Michaelis–Menten (MM) elimination from the central compartment, six parallel IV bolus dose groups, and sparse PK sampling over 21 days.

PopED uses mrgsim_q() inside the ff() wrapper; PFIM implements the same structural model as a custom ODE (CENT, PERIPH amounts; observation CP = CENT/V1).

Interactive workflow:

Study

Item Value
Route Single IV bolus
Dose groups (mg) 0.03, 0.1, 0.3, 1, 3, 10
Subjects per group 6
Sampling (days) 1 h, 4 h, 1, 3, 7, 14, 21

PopED passes dose as DOSE (mg) and multiplies by 1000 in the simulation data set (central amount in µg). PFIM uses the same convention: dose = DOSE_mg × 1000 on CENT.

Structural model

mrgsolve / PopED (model_poped.cpp):

ke  = CL/V1;  k12 = Q/V1;  k21 = Q/V2;  CP = CENT/V1
dCENT/dt  = k21*PERIPH - k12*CENT - VMAX*CP/(KM+CP) - ke*CENT
dPERIPH/dt = k12*CENT - k21*PERIPH

PFIM ODE (equivalent):

modelEquations = list(
  Deriv_CENT = paste(
    "{ CP = CENT/V1; ke = CL/V1; k12 = Q/V1; k21 = Q/V2;",
    "k21*PERIPH - k12*CENT - VMAX*CP/(KM + CP) - ke*CENT }"
  ),
  Deriv_PERIPH = "{ k12 = Q/V1; k21 = Q/V2; k12*CENT - k21*PERIPH }"
)
outputs = list(RespPK = "CENT/V1")

Population parameters and residual error

PopED bpop, IIV (d), and proportional error (feps.prop, sigma = 0.15):

modelParameters = list(
  ModelParameter(name = "CL",   distribution = LogNormal(mu = 0.5,  omega = 0.2)),
  ModelParameter(name = "VMAX", distribution = LogNormal(mu = 20,   omega = 0.2)),
  ModelParameter(name = "KM",   distribution = LogNormal(mu = 1.2,  omega = 0)),
  ModelParameter(name = "V1",   distribution = LogNormal(mu = 2.5,  omega = 0.1)),
  ModelParameter(name = "Q",    distribution = LogNormal(mu = 10,   omega = 0)),
  ModelParameter(name = "V2",   distribution = LogNormal(mu = 4,   omega = 0))
)

modelError = list(
  Proportional(output = "RespPK", sigmaSlope = 0.15)
)

Log-normal IIV on CL, VMAX, and V1 only (omega = 0 on KM, Q, V2), matching PopED d = c(CL = 0.2, VMAX = 0.2, V1 = 0.1).

Design

sample_days = c(1 / 24, 4 / 24, 1, 3, 7, 14, 21)
doses_mg    = c(0.03, 0.1, 0.3, 1, 3, 10)

fakinumab_arm = function(dose_mg) {
  Arm(
    name = paste(dose_mg, "mg"),
    size = 6,
    administrations = list(
      Administration(
        outcome = "CENT",
        timeDose = 0,
        dose = dose_mg * 1000
      )
    ),
    samplingTimes = list(
      SamplingTimes(outcome = "RespPK", samplings = sample_days)
    ),
    initialConditions = list(CENT = 0, PERIPH = 0)
  )
}

design_fakinumab = Design(
  name = "fakinumab",
  arms = lapply(doses_mg, fakinumab_arm)
)

evaluation_fakinumab = Evaluation(
  name = "Fakinumab PopED mrgsolve",
  modelEquations = modelEquations,
  modelParameters = modelParameters,
  modelError = modelError,
  outputs = outputs,
  designs = list(design_fakinumab),
  fimType = "population",
  odeSolverParameters = list(atol = 1e-8, rtol = 1e-8)
)

Test plot (population mean)

plot_fakinumab_test = function(evaluation, n_points = 200) {
  model = defineModelWrapper(defineModelType(evaluation), evaluation)
  arms  = S7::prop(S7::prop(evaluation, "designs")[[1]], "arms")
  times = seq(0, 21, length.out = n_points)

  curves = purrr::list_rbind(purrr::map(seq_along(arms), function(i) {
    plot_arm = arms[[i]]
    S7::prop(plot_arm, "samplingTimes") = list(
      SamplingTimes("RespPK", times)
    )
    m = defineModelAdministration(model, plot_arm)
    y = evaluateModel(m, plot_arm)
    data.frame(
      time = y$RespPK$time,
      CP = y$RespPK$RespPK,
      dose = S7::prop(arms[[i]], "name")
    )
  }))

  ggplot(curves, aes(time, CP, color = dose)) +
    geom_line(linewidth = 0.9) +
    scale_y_log10(limits = c(0.01, 1e4)) +
    labs(
      x = "Time from dose (days)",
      y = expression(C[P] ~ "(mg/L, log scale)"),
      color = "Dose group",
      title = "Fakinumab — population mean PK by dose"
    )
}

plot_fakinumab_test(evaluation_fakinumab)

Interpretation: the design is well identified in both tools (det(FIM) > 0). Fixed effects and IIV RSE are same order of magnitude; remaining differences come from PopED’s mrgsolve-based likelihood linearisation vs PFIM’s finite-difference gradients on the ODE, and from how very small doses (0.03 mg) interact with MM clearance at the numerical tolerance.

Sampling windows (PopED)

PopED evaluates window efficiency with plot_efficiency_of_windows() (±1 h on day 1, ±3 h on later samples). In PFIM, use SamplingTimeConstraints on each arm and re-run run() or an optimization algorithm to explore local sampling windows.
